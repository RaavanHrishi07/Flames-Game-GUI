# 🔥 FLAMES Game GUI

A fun and interactive **FLAMES Relationship Calculator** built using Python and Tkinter. Enter two names and discover their relationship result through the classic FLAMES game in a modern, colourful graphical interface.

## ✨ Features

- 🎨 Modern and colourful Tkinter GUI.
- ❤️ Calculates all six FLAMES relationship outcomes.
- 🤝 Displays a unique emoji for each result.
- 👤 Accepts two player names as input.
- ⚠️ Input validation for empty or invalid names.
- 🧹 Clear button to reset the inputs and results.
- ⌨️ Enter key support for convenient interaction.
- 🖥️ Lightweight application with no external dependencies.

## 💻 Technologies Used

- **Language:** Python
- **GUI Framework:** Tkinter
- **Concepts:** String Manipulation, Lists, Loops and Conditional Logic

## 📋 FLAMES Categories

The game calculates one of the following six outcomes:

| Letter | Relationship | Emoji |
|---|---|---|
| F | Friends | 🤝 |
| L | Love | ❤️ |
| A | Affection | 🥰 |
| M | Marriage | 💍 |
| E | Enemy | ⚡ |
| S | Siblings | 👫 |

## ⚙️ Requirements

- Python 3.x
- Tkinter (included with most standard Python installations)

No additional Python packages are required.

## 🎮 How to Play

1. Launch the application.
2. Enter the first player's name.
3. Enter the second player's name.
4. Click the **Calculate FLAMES** button.
5. View the calculated relationship and its emoji.
6. Click **Clear** to start a new calculation.

## 🧠 How It Works

The application follows the traditional FLAMES game logic:

1. Takes two names as input.
2. Removes common characters from both names.
3. Counts the remaining characters.
4. Uses the remaining count to eliminate letters from the FLAMES sequence.
5. Displays the final relationship category.
